# Школьные темы

Небольшой статический сайт с наглядными школьными уроками, примерами и интерактивной самопроверкой. Серверная часть, база данных, учётные записи и сбор аналитики не используются.

Каталог включает историю, литературу, математику, русский язык, биологию, географию, английский и информатику. Правила создания новых уроков собраны в [`AGENTS.md`](AGENTS.md).

## Локальный запуск

Нужен Node.js 22 или новее.

```bash
npm run check
npm run serve
```

После запуска сайт доступен по адресу `http://127.0.0.1:4173`.

## Как добавить урок

1. Выбрать предмет из `content/subjects.json`.
2. Скопировать структуру существующего урока в `content/<предмет>/<slug>/`.
3. Заполнить `meta.json`: `slug`, `subject`, `title`, `grade`, `duration`, `description`, `order`.
4. Создать самостоятельный `index.html` с объяснением, наглядным примером и самопроверкой.
5. Выполнить `npm run check`.

Урок должен работать с клавиатуры и на телефоне, давать объяснение после ошибки и позволять пройти проверку повторно. Внешние скрипты и отправка ответов на сервер не нужны.

## Сборка и публикация

`npm run build` создаёт готовый статический сайт в `dist/`. При каждом push в `main` GitHub Actions проверяет проект и публикует эту папку в GitHub Pages.

## Production

Основной домен — `https://school.kunini.ru`. Серверный checkout находится в `/var/apps/school-tests`; Nginx раздаёт атомарно переключаемый symlink `current`.

```bash
./ops/deploy.sh
./ops/setup-nginx.sh # только при первичной настройке TLS/Nginx
```

`deploy.sh` принимает только чистый checkout, выполняет проверки, создаёт отдельный каталог выпуска и переключает `current` одной операцией. Если публичная проверка не проходит, symlink возвращается на предыдущий выпуск. Для ручного отката нужно так же переключить `current` на нужный каталог из `releases/`.
